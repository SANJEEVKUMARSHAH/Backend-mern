## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SANJEEVKUMARSHAH/Backend-mern.git
```

### 2. Navigate to the project directory

```bash
cd Backend-mern
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and add the required configuration.

```env
PORT=3000
```

### 5. Run the server

If your entry file is `server.js`, run:

```bash
node server.js
```

If your project has a development script configured, you can also use:

```bash
npm run dev
```
